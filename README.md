## 项目简介

中国大陆 ↔ 东南亚的跨境供应链 skill。使用者只要给出货品、出发地和目的地，就能尽快拿到可核对的源头工厂或商家、货代与物流、官方税费，以及挂在具体公司上的清关履约方案。

A practical skill for China–Southeast Asia supply-chain desk research: named factories or suppliers, forwarders, official duty and access checks, and fulfillment options hung on specific companies—before anyone sends an RFQ.

## 免责声明

本项目只提供供应链方向的初步参考信息，包括可核对的资源线索、官方公开信息和方案候选。它不构成法律、海关、税务、投资或交易建议，也不在实际商业场景中提供任何确定性结论。是否成交、如何签约、如何报关订舱，以及最终成本与能否放行，须以官方当期规定、有效报价和有资质机构的意见为准。本项目不代替货代报价、海关预裁定、订舱或报关。

## 它能做什么

- **两条独立链路**：从中国出口到东南亚，或从东南亚采购并进口到中国。两条链逻辑不同，不会混跑。
- **先给资源，不必先有价格**。货品、起点、终点齐了就开始检索，并在对话里一次交清第一份资源包。询价是可选的后续步骤，不是出门门槛。
- **第一交付包含**：商品大类定位与 HS 候选、已核实的税费（带来源和查询日期）、已打开页面的工厂或商家、货代与物流名单、以及挂在具体公司上的几条履约方案。
- **受注册限制的品类**（例如需要检疫或境外注册的农产品）会同时给出注明日期的官方名录候选。没有公开电话或邮箱时，联系方式留空，但不会只交两三家已打开网站的公司，让人误以为全市场只剩这些。
- **品质过滤**：使用者要求最高品质或核心产地时，先在官方可进境名单上按产地、品种、形态过滤。注册只证明可以合法进境，不证明品质最高。
- **联系渠道核验**：已打开页面上的电话、邮箱，会尽可能做轻量核验（域名、证书、占位号码、中英文信息不一致等）。核验通过也不等于对方一定会回复。
- **可选后续**：使用者确认短名单后，再起草询价；收回同一口径有效报价后，再比较落地成本。明确要求时，用自带的九页仪表盘模板生成方案报告 PPT；没有报价的位置直接留白。

## 它不能做什么

- 不代替货代报价、海关预裁定、订舱、报关，或许可证申办。
- 没有同一口径的有效报价时，不宣布「最佳落地成本」或编造赢家。
- 打开公司官网或平台页，只表明「仅打开页面」，不等于已核实产线、执照或已询到价。
- 不提供低报、瞒报或灰色清关建议。页面上的「双清包税」等广告语可以记录，但不会列为方案。
- 不把某次下载的税则或名录当成长期有效的权威数据。官方税率、准入和注册名单必须按当次查询核对。

## 范围

地理范围仅限中国大陆与东南亚六个目的地或来源地：新加坡、马来西亚、泰国、印度尼西亚、越南、菲律宾。

商品按独立大类处理，不混用名单和流程：

- 普通货物：支持执行
- 鲜活或冷链农产品：支持执行，但必须过冷链和检疫闸门
- 包装食品或保健品、化妆品、带电 / 无线电 / 3C：条件执行，闸门未过不得建议成交
- 其他需证：不硬做
- 禁限：不可做

## 如何使用

1. 把 `SKILL.md` 放到你的 AI 助手或 Cursor 的 skill 目录中，并保留旁边的 `template/` 文件夹。操作顺序见 [WORKFLOW.md](WORKFLOW.md)。
2. 直接给出货品、出发地和目的地，例如：从义乌出口冲锋衣到马来西亚，或从马来西亚采购榴莲进口到深圳。
3. 先阅读对话里的资源包和缺口，再决定是否授权询价，或是否生成 PPT 报告。

本 skill 由执行它的助手按正文检索和核对官方来源。仓库本身不提供实时运价，也不内置海关数据库。

## 持续优化

方法会随使用继续进化，公开渠道是本仓库的 Issue 和 Pull Request。请先阅读 [CONTRIBUTING.md](CONTRIBUTING.md)。

- 使用中发现检索、交付或链路问题，请开 Issue。
- 只改进 `SKILL.md`、模板和文档；不要提交私人名录、报价、对话或税则文件。
- 不要把某一次查到的税率或注册名单写成长期有效的事实。已确认的方法教训由维护者写回 skill，并记入 [CHANGELOG.md](CHANGELOG.md)。
